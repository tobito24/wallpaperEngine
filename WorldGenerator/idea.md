# WorldGenerator: idea

## Idea

A Pokémon-style pixel-art landscape that builds itself tile by tile with Wave Function Collapse (WFC) and then idles until the
user reloads. Where this repo started.

## Not

- Not endless and not interactive beyond highlight selection: one generated picture.
- Not the base for new work: later projects were built from or against it, but its Wallpaper Engine wiring is the oldest in the repo.

## Plan

- [x] WFC over a flat grid with edge-compatible tiles and rules
- [x] Tile set and tickrate/accuracy sliders
- [x] Freeze and write highlight modes
- [x] In-wallpaper GUI mirroring the property panel
- [x] Publish

## Done when
