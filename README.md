# wallpaperEngine

Development of animated wallpapers for **Wallpaper Engine (Steam)**, a collection of visually worked-out ideas.

- `WorldGenerator/`: procedural landscape generator (done, published)
- `InfinityWalker/`: walking-character iteration on WorldGenerator (published, paused)
- `TileGridBase/`: reusable base for 2D tile-grid projects, TypeScript + Vite (active, meant to be cloned)
- `ColorWar/`: rainbow cyclic-dominance tile automaton, cloned from TileGridBase (done for now, published)
- `WorldNoise/`: noise and biome terrain generation, cloned from TileGridBase (active)
- `FirstTestStuff/`: legacy experiments
- `DesignCorner/`: Photoshop tileset sources, autotile template, ground textures (`DesignCorner/private/` is git-ignored)

Every project follows one idea and has an `idea.md` with its plan. See [CLAUDE.md](CLAUDE.md) for the rules and the map to
[docs/](docs/), and `.claude/skills/` for the project skills (`/new-project`, `/publish-prep`, `/docs-maintenance`).
